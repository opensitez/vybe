# Lua raw AST pipeline measurements, 2026-10-03

Command:

```sh
DEVELOPER_DIR=/Library/Developer/CommandLineTools cargo run --release --manifest-path crates/grameo/conformance_tests/Cargo.toml --offline --example lua_ast_baseline
```

Local aarch64 machine; rustc 1.97.1 (8bab26f4f 2026-07-14), Homebrew. Each pipeline uses 10 warmups and 101 samples; cells are median/p95 microseconds. This is one run, not an acceptance gate. The release build completed before timing. Complete AST fields, spans and raw module policies are structurally compared before each workload is measured.

Timings include source indexing, matching, AST construction, journal cleanup and output destruction. Reference/native pair paths include their walker. Direct paths have no capture tree or walker. Final compiler-dependent Lua normalization, compiler/WASM emission, startup, peak memory and generated-size gates are outside this experiment.

`tiny` is arithmetic; `operators100` has 100 `a * 2` terms joined by addition; `calls30` has 30 method/call/member/index chains joined by addition. `fields200` contains 100 named plus 100 computed table fields with calls; `functions20` contains 20 function values with fixed/rest parameters, a local initializer and multiple returns. Module workloads contain one small declaration/return, 200 declarations with calls/arithmetic, or 20 colon methods with generic loops, conditionals and returns. Sources are constructed explicitly in the example.

Pratt cooperation reduces time on most of these native direct-AST workloads, but the operator-heavy case barely improves. All native paths remain slower than the reference. Prior runs had much larger tails and different medians; do not compare runs as a regression test or infer end-to-end compiler speed. Generated matching/lexical dispatch and further profiling remain necessary. Production defaults remain unchanged.

## Recovered literal-choice experiment

A follow-up invocation of the same command compared scheduled versus certified literal-choice failure dispatch using 10 paired warmups and 101 interleaved samples (alternating which variant runs first). Full AST output is checked before timing. The Lua Pratt generated fixture explicitly enables this experimental option; ordinary generated programs and resolved grammars leave it disabled. The scheduled adapter suppresses only this certificate and forwards the other program behavior. Results include all source/index/build/destruction costs, median/p95 in microseconds:

| Workload | Scheduled | Certified |
| --- | ---: | ---: |
| tiny | 14.96/15.42 | 16.00/16.25 |
| operators100 | 1010.21/1154.88 | 1005.17/1135.21 |
| calls30 | 1594.12/8040.58 | 1542.79/6710.33 |
| fields200 | 6044.62/14250.42 | 7187.42/14528.04 |
| functions20 | 1410.79/5622.42 | 1412.62/5455.79 |
| module_tiny | 57.08/95.92 | 56.12/68.04 |
| module_declarations200 | 8614.58/11828.42 | 8649.29/10533.21 |
| module_methods20 | 1871.21/2618.50 | 1811.42/2468.46 |

The follow-up run was noisy and results are mixed, with tiny-expression and table regressions. Keep the optimization opt-in. Do not compare these medians against the earlier independent run as a regression gate. A terminal-rule fusion experiment was also removed after it failed to improve the measured Lua workloads.

## Direct numeric-loop binding baseline

After the resumed numeric-loop binding, the example additionally measures `module_numeric20`: twenty numeric loops with integer bounds, an explicit float step, a table assignment and a closure capturing that loop's variable. All four paths must produce identical complete raw modules before timing. Same toolchain/command, 10 warmups and 101 samples; timing includes source indexing, construction, numeric/closure policy edits and output destruction. This is a separate, noisy run with no regression or migration claim.

| Workload | Reference + walker | Native + walker | Native direct AST | Native Pratt AST |
| --- | ---: | ---: | ---: | ---: |
| module_numeric20 | 999.58/1659.00 | 2905.50/4123.42 | 2688.79/3391.21 | 1944.50/2391.71 |

Microseconds, median/p95. Paired literal-choice scheduled/certified medians were 1983.04/1978.96 µs (p95 2463.42/2571.08). The native Pratt binding remains about twice the reference median on this workload; correctness coverage and removing user-subtree cloning do not establish the project's performance objective.
